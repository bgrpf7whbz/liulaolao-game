P0-B　节点全部失效、出门前就点不动（最高优先）

现象：所有节点交互区失效，第一个节点也点不动。

根因判断：第一视角改造改动坐标系/渲染层，事件绑定或命中判定被连带破坏。

改法

1. 排查点击事件是否在第一视角分支中被解除、重复绑定或绑到已销毁的层（DOM / canvas）。

2. 第一视角若引入相机偏移或视口缩放，所有点击判定必须套用同一坐标变换；禁止一处用屏幕坐标、一处用世界坐标。

3. 统一基准视口 1280×800，热点采用 0-1 相对坐标，命中判定在同一坐标系内完成。

4. 优先验证首个节点：确认监听已挂载、enabled === true、资源路径无 404。

验收：进入首节点即可正常触发交互；视角切换前后命中区位置一致。

P0-A　第一视角下人物变回「方块人」

现象：切到第一视角后人物退化为占位方块。

根因判断：第一视角分支走了默认兜底资源，或立绘纹理未重新绑定。

改法

1. 视角切换时不重建人物对象，只切换相机与人物的朝向参数（faceToCamera）；两种视角共用同一套立绘贴图。

2. 检查第一视角下的资源加载路径是否因改动导致 404，从而回落到方块占位。

3. 所有角色立绘补加载失败告警（console.warn 带资源名），便于定位缺图。

验收：第一视角下板儿、王熙凤、平儿、周瑞家的、贾蓉等均正常显示立绘，无方块。

注：A、B 同源，一并排查，不分开修。

P0-C　序幕词汇超纲（教学对象 HSK 2.0 五级）

改法

1. 措辞基准明确为 HSK 2.0 五级；HSK 3.0 仅作词汇筛选参照，不用于此处水平定位。开题报告底本说明段遗留的「汉语中级学习者」旧口径一并修正。

2. 序幕逐句过词：超五级词改写为五级内表达；无法替换的专名（人名、器物名、职官名）保留，首次出现处给简短解释。

3. 长句拆短，避免多层修饰；文言化表达（如「轩敞森严」「美服华冠」）不进序幕正文，改用平实说法。

4. 加机械校验：序幕全文过 HSK 2.0 五级词表，输出超纲词标记与替换清单，再人工定稿。

验收：超纲词比例可控，专名均有首现解释；水平定位表述与开题报告口径一致。

P0-D　第一视角规则（本版方案：对话保留刘姥姥全脸立绘）

前提：第一视角完整改造难度过高，对话节点保留刘姥姥全脸立绘。

改法

1. 按节点类型分流，不做一刀切禁用：

• 对话/台词节点（perspective: "dialogue"）：允许出现刘姥姥全脸立绘，按常规立绘＋对话框表现。

• 剧情 CG、行走/探索镜头（perspective: "first"）：仍保持第一视角，不出现刘姥姥全脸，仅可用手、衣袖、包袱局部。

2. ch_liu_laolao（刘姥姥立绘）不移出渲染池，改由节点 perspective 字段控制引用权限。

3. 保留以下约束：

• 对话节点内其他人物（板儿、王熙凤、平儿、周瑞家的、贾蓉等）一律 faceToCamera: true，身体与视线朝向镜头。

• 含刘姥姥全脸的旧 CG 仍移出正式节点，或改标 usage: "recall|transition"。

4. 与时序相关：P0-A 优先级更靠前——既然立绘要保留，立绘必须能正常加载显示。第一视角切换时人物对象不重建、共用同一套贴图、补加载失败告警。

验收

• 对话节点：刘姥姥全脸立绘正常显示，无方块；对方人物面向镜头。

• CG/探索节点：不出现刘姥姥全脸，仅手/衣袖/包袱局部。

• 两种视角间切换时人物立绘不丢失、不退化。

P0-E　人物移动生硬 → 走位改由镜头承担

改法

1. 项目模式确认为「纯互动叙事」：MAP 系列不作为可走地图，转教学展示/转场用图；节点内取消角色长距离行走。

2. 移动由镜头承担：camera.push / pan / tilt / slowPan，缓动统一 easeInOutCubic，禁止线性 linear。

3. 过门槛、掀门帘处加短暂视线遮挡过渡（黑场/虚焦淡入淡出，≤400ms）。

4. 他人入场改为「入画 → 停留 → 面向镜头说话」，禁止直线平移穿越画面，过渡补 2～3 帧或一次虚焦淡入。

5. 板儿同行位置固定为玩家侧前方偏下，出现方式同为入画。

验收：无线性平移；镜头运动有缓入缓出；过门槛有遮挡过渡。

P1　文化热点贴回画面物件坐标

问题：全程未见可点击文化热点。

改法

1. 热点不做独立 UI 按钮，改为贴附画面中物件位置的点击区，0-1 相对坐标，随视口缩放自适应。

2. 交互反馈：可点物件带轻微呼吸/微光提示；点击弹出三层解释（表层／深层／出处）；点击即收入收藏式文化手册。

3. 热点不参与结局判定，只影响文化认知深度与手册收集度。

验收：对应节点可见热点提示；点击弹出三层解释并可收入手册；结局判定不受影响。

待确认：热点总数取 15 还是 8。当前按 8 实现，若走 15 方案另补 7 个物件图标与挂点。

P2　静态版本 localhost:8080 无法访问

需提供：浏览器控制台报错全文、页面源码（index.html）、目录结构。

先自查

1. 静态资源是否用相对路径（绝对 / 路径在子目录部署会 404）。

2. JSON 素材/配置是否被 CORS 或 file:// 协议拦截；若用 fetch 读本地 JSON，需起本地服务器而非双击打开。

3. 8080 端口是否被占用、服务是否真的启动。

注：与 P0-A、P0-B 大概率同源（脚本未正确加载／事件未绑定），修 B 时一并验证。

素材命名规范

整体色调明亮清朗、光线充足、画面通透，不做阴暗压抑；画面人物前后形象一致，以已产出立绘/设定卡为准。
